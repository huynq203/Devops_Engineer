* Build dự án
1. Build Dự án Nodejs
- Cài nodejs và npm: sudo apt install nodejs npm -y
- Nâp cấp Phiên bản node lên 18: curl -s https://deb.nodesource.com/setup_18.x | sudo bash
	=> Sau đó cài lại npm: apt install nodejs -y
- Cài thư viện dự án: npm i
- Build dự án: npm run build
- Tạo user: adduser todolist
- Phân quyền chủ sỡ hữu và nhóm sở hữu: chmod -R 777 /projects/todolist/dist/
- Tạo file todolist.conf ở /etc/nginx/conf.d/
server{
 listen 8081;
 root /home/huynq/projects/todolist/dist/;
 index index.html;
 try_files $uri $uri/ /index.html;
}
- Kiểm tra kết nối: nginx -t
- Restart nginx: systemctl restart nginx => nêm sử dụng reload: systemctl reload nginx
- Thêm user vào nhóm sở hữu: usermod -aG todolist www-data
- Restart nginx: systemctl restart nginx
- Kiểm tra log: sudo tail -f /var/log/nginx/error.log
- Tìm kiếm dữ liệu file: sudo nginx -T | grep -n "listen 8081"

** Cài + tạo db

B5. Do db là mariadb => Cài mariadb: apt install mariadb-server -y
- Sửa cấu hình mariadb
 + systemctl stop mariadb
 + vi /etc/mysql/mariadb.conf.d/50-server.cnf => Cấu hình bin_address = 0.0.0.0
 + systemctl restart mariadb
 + mysql -u root => show databases; => create database shoeshop; => Tạo database
 + create user 'shoeshop'@'%' identified by 'shoeshop'; => Tạo user
 + GRANT ALL PRIVILEGES ON shoeshop.* TO 'shoeshop'@'%'; => Gán full quyền
 + flush privileges; => Lưu lại những thứ đã thay đổi
 + systemctl restart mariadb
