- Các câu lệnh linux
pwd: vị trí hiện tại
whoami: Đang đăng nhập trong phiên với user nào

* Xem thông tin file/folder
ls: Show toàn bộ file trong folder
ls -l: Show theo list
ls -a: Show những file ẩn
ls -t: Show những file từ mới nhất đến cũ nhất
ls -lta: Show toàn bộ file trong folder

* Tạo folder
mkdir name_folder: Tạo folder name_folder
mkdir -p name_folder1/namefolder2: Tạo name_folder1 và name_folder2

* Tạo file
touch name_file: Tạo file name_file

* Xóa file
rm name_folder || name_file: Xóa foder hoặc file
rm -r name_folder || name_file: Xóa folder hoặc file
rm -rf name_folde || name_file: Xóa folder hoặc file không cần hỏi lại

* Copy file
cp file_1 url: Copy file_1 vào url
cp -r folder_1 url: Copy folder vào url

* Move file hoặc folder
mv file_1 file: Chuyển file_1 sang thư mục hiện tại và đổi tên thành file
mv file_1 folder: Chuyển file_1 sang thư mục hiện tại và đổi tên thành folder

* Ghi file
echo "DevOps": In nội dung
echo "DevOps" > file_name: Hiển thị nội dung DevOps và ghi vào file_name
echo "DevOps1" > file_name: Hiển thị nội dung DevOps1 và ghi đè DevOps ở file_name
echo "DevOps2" >> file_name: Hiển thị nội dung DevOps và ghi thêm dòng DevOps2 ở file_name
cat file_name: Đọc nội dung trong file_name
history: Nội dung câu lệnh đã từng gõ

* Tìm kiếm bằng tail
tail -n 1 file_name: Hiển thị 1 dòng cuối cùng của file_name
tail -f file_name: Xem dữ liệu realtime => Thoát khỏi Ctrl+C

* Tìm kiếm từ khóa ở file
grep keyword file_name: Tìm kiếm keyword trong file_name
grep keyword *.log: Tìm kiếm keyword nhiều file có đuôi .log
grep -i keyword file_name: Tìm kiếm không phân biệt chữ Hoa/thường
grep -n keyword file_name: Hiển thị vị trí số dòng keyword đứng dòng nào
grep -c keyword file_name: Đếm số từ có từ keyword
grep -E "keyword1,keyword2" filename: Tìm dòng chứa keyword1 hoặc keyword2 (tìm nhiều từ)

* Tìm kiếm file/folder:
find . -name "file_name" : Tìm thư mục hiện tại có tên là file_name
find . -iname "file_name" : Tìm thư mục hiện tại có tên là file_name (Không pb hoa/thường)

* Phân chủ sở hữu / Nhóm sở hữu
chown Chusohuu:Nhomsohuu folder/file : Phân quyền của 1 folder/file thành chusohuu/nhomsohuu khác

* Phần quyền truy cập
chmod u=rwx folder_name: Phân quyền truy cập rwx cho chủ sở hữu ở folder_name => u đại diện cho chủ sở hữu
chmod g=rwx folder_name: Phân quyền truy cập rwx cho chủ sở hữu ở folder_name => g đại diện nhóm sở hữu
chmod o=rwx folder_name: Phân quyền truy cập rwx cho chủ sở hữu ở folder_name => o đại diện cho nhóm/người khác
	+ r: read => Đọc
	+ w: write => Viết
	+ x: excute => Thực thi
chmod u=rwx,g=rw,o=wx folder_name: Phân quyền nhanh
Truy cập kiểu số: r=4,w=2,x=1
chmod 777 foler_name: Phần quyền truy cập full cho 3 đối tượng cho chủ sở hữu, nhóm sở hữu,người khác mỗi folder_name (con sẽ k phân quyền)
chmod -R 777 folder_name: Phân quyền all

- Phân quyền chủ sỡ hữu và nhóm sở hữu: chmod -R 777 /projects/todolist/dist/
- Tạo file todolist.conf ở /etc/nginx/conf.d/
server{
 listen 8081;
 root /home/huynq/projects/todolist/dist/;
 index index.html;
 try_files $uri $uri/ /index.html;
}
- Kiểm tra kết nối: nginx -t
- Restart nginx: systemctl restart nginx
- Thêm user vào nhóm sở hữu: usermod -aG todolist www-data
- Restart nginx: systemctl restart nginx
- Kiểm tra log: sudo tail -f /var/log/nginx/error.log
- Tìm kiếm dữ liệu file: sudo nginx -T | grep -n "listen 8081"
