- Tạo một server riêng => Tạo snapshot từ server đầu
- Cài package gitlab server vào link sau: https://packages.gitlab.com/gitlab/gitlab-ee/packages/ubuntu/focal/gitlab-ee_14.4.1-ee.0_amd64.deb
B1. curl -s https://packages.gitlab.com/install/repositories/gitlab/gitlab-ee/script.deb.sh | sudo bash
B2. sudo apt-get install gitlab-ee=14.4.1-ee.0
- Setting server
* Thêm domain
B1. vi /etc/hosts => Thêm địa chỉ và domain: 192.168.198.130 gitlab.elroydevops.tech
B2. vi /etc/gitlab/gitlab.rb
    Sửa: external_url 'http://gitlab.example.com' => external_url 'http://gitlab.elroydevops.tech'
B3. sudo gitlab-ctl reconfigure => Lưu cấu 
B4. Cập nhật file hosts trên laptop cá nhân C:\Windows\System32\drivers\etc\hosts: 192.168.198.130 gitlab.elroydevops.tech
B4. Truy cập web http://gitlab.elroydevops.tech
B5. Tài khoản/password lấy trên server: cat /etc/gitlab/initial_root_password => root / password (trong file) => Đổi password root / Quochuy221003@! - huynq1/1234567890

** Câu lệnh gitlab
gitlab-ctl status: Kiểm tra trạng thái gitlab
gitlab-ctl restart: Restart lại service gitlab

* Git commit conventional
- Cấu trúc commit chuẩn: <type>(scope): <description>
vd: feat(auth): add login with Google
- Các type phổ biến
feat - Thêm feature mới => Dùng khi thêm api, function,...
fix - sửa bug => Dùng khi sửa lỗi
docs -  thay đổi tài liệu
config - thay đổi file cấu hình
style - format code (không ảnh hưởng logic)
refactor - refactor code => tái cấu trúc code
test - thêm hoặc sửa test
chore - công việc phụ (build,config)
perf - cải thiện perormance
ci - thay đổi CI/CD
