##=======================Docker=======================##
* Các câu lệnh docker
docker ps || docker ps -a : Hiển thị các container
docker images: Hiển thị các images
docker rm -f container_id || container_name: Xóa container container_id || container_name
docker rm -f $(docker ps -a): Xóa toàn bộ docker có trên server
docker rmi -f images_id || images_name
docker start container_id: Chạy docker
docker stop container_id: Dừng docker

docker system df : Kiểm tra trước khi dọn
docker system prune -af: Xóa các container không dùng
docker builder prune -af: Xóa các cache build
sudo truncate -s 0 /var/lib/docker/containers/*/*.log : dọn log

=======================Cài docker=======================
B1. Tạo folder tools
B2. Tạo folder docker
B3. Ghi file vi install-docker.sh:
#!/bin/bash
sudo apt update
sudo apt install -y apt-transport-https ca-certificates curl software-properties-common
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /usr/share/keyrings/docker-archive-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt update
sudo apt install -y docker-ce
sudo systemctl start docker
sudo systemctl enable docker
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose
docker --version
docker-compose --version
B4. Chạy file docker-install.sh có 3 cách chạy:
    - C1: ./docker-install.sh
    - C2: sh docker-install.sh
    - C3: bash docker-install.sh

** Keyword trong Dockerfile
FROM node:20 : kéo version nodejs về server
WORKDIR : chỉ định thư việc làm việc cho container
COPY : copy source code vào container || COPY . . : dấu chấm đầu tiên vị trí hiện tại source code - dấu chấm thứ 2 vị trị hiện tại của container(tức là vị trí WORKDIR)
RUN : Chạy câu lệnh
ENV : Khai báo biến môi trường
EXPOSE: Định nghĩa container chạy port nào => EXPOSE 80 : port server EXPOSE và port container là 80 => VD 7777:80 lúc chạy container
CMD : Xác định lệnh và giá trị mặc định
ENTRYPOINT: giữ nguyên 1 lệnh cố định và cho phép lệnh được chỉ định khi chạy container vào cuối

** Tư duy viết Dockerfile tối ưu
- Chọn images đúng version dự án:
    + Chọn images đúng version dự án
    + Chọn images từ các nguồn official, verified, 
    + Chọn base image là alpine => giúp cấu hình nhẹ hơn
